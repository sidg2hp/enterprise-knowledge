Knowwise - How to Use

This repository implements an offline-friendly evidence-first vertical slice
with optional decision-intelligence integrations. It accepts UTF-8 TXT and
Markdown files, stores deterministic chunks, and returns answers with
citations that resolve to returned source passages. BM25 is the default;
optional FAISS/vector retrieval, Ollama embeddings/chat, and read-only Neo4j
context are available when configured. PDF extraction, authentication, and
document permissions are not implemented yet.

1. Start the application

Recommended:
  docker compose up --build

Local backend:
  cd backend
  python -m venv .venv
  .venv\Scripts\python.exe -m pip install -r requirements.lock
  .venv\Scripts\python.exe -m uvicorn main:app --reload

Local frontend, in a second terminal:
  cd frontend
  npm ci
  npm run dev

2. Use the UI

Open http://localhost:3000. Add `samples/handbook.md`, wait for it to appear
as Ready, then ask: "What does the handbook require?" Expand an evidence card
to inspect the exact passage and stable citation ID. The answer metadata shows
the selected domain, retrieval mode, generation mode, and groundedness proxy.
Ask an unrelated question to see the explicit abstention state.

3. Use the API

  curl -F "file=@samples/handbook.md" http://localhost:8000/documents
  curl http://localhost:8000/documents
  curl -H "Content-Type: application/json" \
    -d '{"query":"What does the handbook require?"}' \
    http://localhost:8000/query

Operational endpoints are `/healthz` for liveness and `/readyz` for the
knowledge-store readiness check. See README.md for the complete setup,
testing, evaluation, optional Ollama/Neo4j setup, deployment, security
limitations, and roadmap.
